`create-typescript-monorepo-bingo` is a one-stop-shop solution to set up a new or existing pnpm monorepo with the latest and greatest TypeScript tooling.
It's a [Bingo](https://create.bingo) template that includes options not just for building and testing but also automated release management, contributor recognition, and more.

> Looking for a single-package repository?
> See [create-typescript-app](https://github.com/JoshuaKGoldberg/create-typescript-app).

## Usage

First make sure you have the following installed:

- [Node.js](https://nodejs.org)
- [pnpm](https://pnpm.io) 12 or newer
- _(optional, but helpful)_ [GitHub CLI](https://cli.github.com) _(you'll need to be logged in)_

Then in an existing repository or in your directory where you'd like to make a new repository:

```shell
npx create-typescript-monorepo-bingo
```

You can read more about the supported runtime modes in their docs pages:

- [**Setting up from the terminal**](./docs/Setup.md): creating a new repository locally on the command-line
- [**Transitioning an existing repository**](./docs/Transition.md): adding or updating this template's tooling in an existing repository
